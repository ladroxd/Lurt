# Code signing policy

**Status:** Lurt releases are not signed yet. This policy describes how they will be signed once the project is accepted by SignPath Foundation.

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## What gets signed

Only `lurt.exe` built from this repository's source by its [release workflow](.github/workflows/release.yml) on GitHub Actions. Every signing request is approved by hand.
